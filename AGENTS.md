# Общие правила

- Перед изменениями изучайте существующие файлы и сохраняйте принятый в них формат.
- Изменяйте только настройки, относящиеся к задаче. Не добавляйте настройки по предположению.
- При изменении темы, пользовательских сочетаний клавиш и других заметных настроек обновляйте `README.md`.
- Не добавляйте в репозиторий пароли, токены и другие секреты.
- Храните настройки каждой программы в отдельном пакете GNU Stow. Пути внутри пакета должны совпадать с путями относительно домашнего каталога.
- После изменения структуры пакета проверяйте установку через `stow -n -v -t "$HOME" <имя-пакета>` и обновляйте команду в `README.md`, если она изменилась.

# Herdr

- В пакет добавляйте только `config.toml`. Сессии, логи, сокеты и release notes остаются локальными.
- Не подключайте `config.toml` через Stow, если репозиторий находится в `~/Documents`: постоянный сервер Herdr не может прочитать такой симлинк из-за ограничений macOS. Копируйте файл командой из `README.md`.
